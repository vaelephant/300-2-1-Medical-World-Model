# 训练相关命令

所有命令默认在**仓库根目录**执行：

```bash
cd /path/to/300-2-1-Medical-World-Model
conda activate mwm          # 或你的虚拟环境
export PYTHONPATH=.         # 未 pip install -e . 时建议加上
```

说明：本阶段为**合成数据研究原型**；指标 ≠ 临床性能。预测与报告均应视为 `research_only`。

---

## 1. 训练前检查（测试）

```bash
# Schema / 合成数据

pytest tests/test_schemas.py tests/test_synthetic_generator.py tests/test_disease_simulator.py \
  tests/test_dataset.py tests/test_world_model.py tests/test_evaluate.py -q
```

## 2. 生成合成训练数据

```bash
# D03 验收量：1000 人（已有可跳过）
PYTHONPATH=. python scripts/generate_data.py --n 1000 --seed 42 --out artifacts/synthetic

# 小队列试跑
PYTHONPATH=. python scripts/generate_data.py --n 300 --seed 42 --out artifacts/synthetic

# 规划量 1 万（较慢、磁盘更多）
PYTHONPATH=. python scripts/generate_data.py --n 10000 --seed 42 --max-visits 12 --out artifacts/synthetic
```

| 参数 | 含义 | 默认 |
|------|------|------|
| `--n` | 患者数 | 1000 |
| `--seed` | 随机种子（可复现） | 42 |
| `--max-visits` | 每条轨迹最大访视数 | 12 |
| `--out` | 输出目录（每患者一个 JSON） | `artifacts/synthetic` |

产物：`artifacts/synthetic/SYN*****.json`、`manifest.json`。

## 3. 训练世界模型

### 3.1 快速 MVP（推荐先跑通）

```bash
PYTHONPATH=. python scripts/train_world_model.py \
  --data artifacts/synthetic \
  --max-patients 300 \
  --epochs 40 \
  --patience 8 \
  --batch-size 32 \
  --device auto \
  --out artifacts/models/mvp
```

### 3.2 更大队列 / 更长训练

```bash
PYTHONPATH=. python scripts/train_world_model.py \
  --data artifacts/synthetic \
  --max-patients 1000 \
  --max-visits 12 \
  --epochs 60 \
  --patience 10 \
  --batch-size 64 \
  --lr 0.0003 \
  --hidden-dim 128 \
  --latent-dim 128 \
  --device auto \
  --out artifacts/models/mvp_1k
```

### 3.3 只训练、结束时不自动评估

```bash
PYTHONPATH=. python scripts/train_world_model.py \
  --data artifacts/synthetic \
  --max-patients 300 \
  --epochs 40 \
  --device auto \
  --out artifacts/models/mvp \
  --no-eval
```

### 3.4 参数说明（`train_world_model.py`）

| 参数 | 含义 | 默认 |
|------|------|------|
| `--data` | 轨迹 JSON 目录 | `artifacts/synthetic` |
| `--out` | 模型输出目录 | `artifacts/models/mvp` |
| `--max-patients` | 最多使用多少患者 | 300 |
| `--max-visits` | 截断访视长度 | 12 |
| `--epochs` | 最大轮数 | 15 |
| `--batch-size` | batch | 32 |
| `--lr` | 学习率 | 3e-4 |
| `--hidden-dim` | GRU/MLP 隐层 | 128 |
| `--latent-dim` | latent 维 | 128 |
| `--device` | `auto` / `cpu` / `mps` / `cuda` | `auto` |
| `--seed` | 划分与初始化种子 | 42 |
| `--patience` | early stopping 耐心 | 10 |
| `--no-eval` | 结束时不跑 test 评估 | 关 |

行为要点：

- **normalizer 只在 train split 上拟合**（防泄漏）
- 保存 `best.pt`（验证集最优）与 `last.pt`
- 默认训练结束在 `reports/eval_<out目录名>.json` 写评估

### 3.5 训练产物

| 路径 | 内容 |
|------|------|
| `artifacts/models/mvp/best.pt` | 最佳权重 + normalizer + 划分索引 + 元数据 |
| `artifacts/models/mvp/last.pt` | 最后一轮 |
| `artifacts/models/mvp/train_meta.json` | 曲线、best_val、可选评估摘要 |
| `reports/eval_mvp.json` | test 集 vs Persistence / rollout（默认开启评估时） |

## 4. 评估世界模型

```bash
# 对已有 checkpoint 做 test 评估
PYTHONPATH=. python scripts/evaluate_model.py \
  --checkpoint artifacts/models/mvp/best.pt \
  --data artifacts/synthetic \
  --split test \
  --device auto

# 指定报告路径
PYTHONPATH=. python scripts/evaluate_model.py \
  --checkpoint artifacts/models/mvp/best.pt \
  --data artifacts/synthetic \
  --split test \
  --report reports/eval_mvp_manual.json

# 看 val / train
PYTHONPATH=. python scripts/evaluate_model.py \
  --checkpoint artifacts/models/mvp/best.pt \
  --split val
```

| 参数 | 含义 | 默认 |
|------|------|------|
| `--checkpoint` | `best.pt` 路径 | `artifacts/models/mvp/best.pt` |
| `--data` | 数据目录 | `artifacts/synthetic` |
| `--split` | `train` / `val` / `test` | `test` |
| `--device` | 设备 | `auto` |
| `--batch-size` | batch | 32 |
| `--context-len` | rollout 上下文访视数 | 3 |
| `--report` | 报告 JSON | `reports/eval_<父目录>.json` |

报告里主要字段：

| 字段 | 含义 |
|------|------|
| `world_model` / `persistence` | 单步 MAE/RMSE（原始特征空间） |
| `mae_mean` | 微平均，**易被 AFP 量级主导** |
| `mae_macro` | 各特征 MAE 再平均 |
| `mae_ex_afp` | 去掉 AFP 后的宏平均 |
| `beats_persistence_mae*` | 是否优于 Persistence |
| `rollout` | 多步自由预测（按访视步 1..H） |
| `research_only` | 恒为 true |

## 5. 训练对照基线（GRU Baseline）

Persistence 无需训练；评估脚本里会自动算。  
另训一个「特征空间一步 GRU」基线：

```bash
PYTHONPATH=. python scripts/train_baselines.py \
  --data artifacts/synthetic \
  --max-patients 300 \
  --epochs 20 \
  --patience 5 \
  --device auto \
  --out artifacts/models/baselines
```

| 参数 | 含义 | 默认 |
|------|------|------|
| `--data` | 数据目录 | `artifacts/synthetic` |
| `--out` | 输出目录 | `artifacts/models/baselines` |
| `--max-patients` | 患者数上限 | 300 |
| `--max-visits` | 访视截断 | 12 |
| `--epochs` | 轮数 | 20 |
| `--batch-size` | batch | 32 |
| `--device` | 设备 | `auto` |
| `--seed` | 种子 | 42 |
| `--patience` | early stopping | 5 |

产物：

- `artifacts/models/baselines/gru_baseline.pt`
- `artifacts/models/baselines/baseline_report.json`（含 vs Persistence）

## 7. 设备与常见问题

```bash
# 强制 CPU
--device cpu

# Mac Apple GPU
--device mps

# NVIDIA
--device gpu   # 脚本参数为 cuda：请用 --device cuda
--device cuda
```

- **`ModuleNotFoundError: packages`**：在根目录加 `PYTHONPATH=.`，或 `pip install -e .`；测试用 `pytest` 不要 `python tests/xxx.py`。
- **重新训练覆盖权重**：换 `--out` 目录，或接受覆盖 `best.pt`。
- **指标看起来很差 / 赢不了 Persistence**：先看 `mae_ex_afp` 与分特征表；`mae_mean` 常被 AFP 拉爆。合成数据上未超越基线时，报告里会如实写 `beats_persistence_*=false`，不要改数。
