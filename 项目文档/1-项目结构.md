### **关键代码模块职责**

| 模块                       | 输入        | 输出           | 必须测试           |
| ------------------------ | --------- | ------------ | -------------- |
| `synthetic_generator.py` | 随机种子、患者数量 | 患者事件轨迹       | 固定种子结果一致       |
| `disease_simulator.py`   | 潜在病情、治疗事件 | 下一时刻状态       | 时间顺序和合理范围      |
| `dataset.py`             | Parquet   | Tensor Batch | Mask 和 Padding |
| `encoder.py`             | 历史特征序列    | Latent Z     | Shape 和梯度      |
| `dynamics.py`            | Z、治疗、时间差  | 下一状态分布       | 多步采样稳定         |
| `decoder.py`             | Latent Z  | 临床指标预测       | 缺失标签处理         |
| `risk_head.py`           | Latent Z  | 事件风险         | 风险值范围与校准       |
| `rollout.py`             | 当前状态、条件序列 | 未来轨迹集合       | 时间单调、输出有限      |
| `inference.py`           | 患者请求      | 预测响应         | 权重版本一致         |
