# 快速启动

```bash
# 环境（示例）
conda create -n mwm python=3.12 -y
conda activate mwm
cd /path/to/300-2-1-Medical-World-Model
pip install -r requirements.txt
pip install -e .          # 让 `import packages...` 在任意启动方式下可用
```

## 跑测试

不要用 `python tests/test_schemas.py`（不会自动把仓库根加入模块路径）。

```bash
# 推荐
pytest tests/test_schemas.py -q

# 或
PYTHONPATH=. python -m pytest tests/test_schemas.py -q
```

若尚未 `pip install -e .`，pytest 仍可用：根目录 `pyproject.toml` 里已配置 `pythonpath = ["."]`。

## 推理 API

```bash
# 需已有 artifacts/models/mvp/best.pt 与 artifacts/synthetic
PYTHONPATH=. python scripts/serve_api.py --device cpu --port 8000
```

- 文档：http://127.0.0.1:8000/docs  
- 健康检查：`GET /health`（含 manifest 派生数据源/seed）  
- 患者：`GET /api/v1/patients`  
- 预测：`POST /api/v1/forecast` `{"patient_id":"SYN00000","horizon":4,"context_len":3}`  
- 产物元数据：`GET /api/v1/provenance`、`GET /api/v1/training`、`GET /api/v1/models/checkpoints`、`GET /api/v1/evaluations/reports`  

响应含 `research_only=true`、`data_source=synthetic`（来源由 `artifacts/synthetic/manifest.json` 派生）。当前 forecast 的 `uncertainty` 为 null，并带 `uncertainty_status.available=false` 与原因说明；不会伪造置信区间。可通过 `MWM_MODELS_DIR`、`MWM_REPORTS_DIR` 覆盖产物目录。

## 前端（Next.js）

另开终端（需 API 已在 8000 端口运行）：

```bash
cd apps/front
cp .env.local.example .env.local   # 首次
npm run dev
```

打开 http://localhost:3000 — 左侧边栏按功能分组：演示总览 / 患者病程 / 病程预测 / 治疗情景 / 模型评估；右侧为全宽功能区。

演示入口：

- http://localhost:3000/world-model — 精选病例（01）+ 病程时间轴（02）+ 预测（03）
- http://localhost:3000/simulation — 治疗情景（04）+ 比较结果与回顾对照（05）
- http://localhost:3000/patients — 患者列表与随访时间轴浏览

流程提示：在 `/world-model` 运行预测后点「下一步 · 比较治疗情景」，会自动把患者、预测起点与步数带到 `/simulation`。

3–5 分钟现场讲解脚本、5 个精选病例与边界话术见 **[4-演示流程.md](4-演示流程.md)**。病例数据源为 `apps/front/lib/demo-cases.json`，可用 `python -m pytest tests/test_demo_cases.py -q` 校验其与当前合成队列一致。
